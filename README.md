# 🌌 Projeto Neo-Aesthetic Vision

## 📒 Descrição
Um projeto experimental que une estética visual e inteligência artificial para criar algo único, minimalista e ao mesmo tempo impactante.  

## 🤖 Tecnologias Utilizadas
- ChatGPT / Copilot para geração de texto e ideias  
- MidJourney / DALL·E para imagens generativas  
- Canva / Figma para ajustes de design e composição final  
- Notion para organização do processo criativo  

## 🧐 Processo de Criação
1. Brainstorm inicial com IA para definir conceito e estética desejada  
2. Geração de imagens com prompts cuidadosamente elaborados  
3. Curadoria e refinamento visual em ferramentas de design  
4. Integração dos elementos em um layout coeso e harmônico  

## 🚀 Resultados
- Uma coleção de visuais minimalistas e altamente estéticos  
- Documentação clara do processo criativo  
- Inspiração para futuros projetos que misturam arte e tecnologia  

## 💭 Reflexão
Criar algo "natty" com IA é um desafio interessante: exige equilibrar a espontaneidade humana com a precisão algorítmica. O resultado é uma estética híbrida, que parece natural mas carrega a assinatura digital da inteligência artificial.
